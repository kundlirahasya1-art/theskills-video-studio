# Claude ke liye niyam (is repo me)

- Ye FFmpeg + Python (sirf standard library) ka video toolkit hai. Naya package install mat karo, network band ho sakta hai.
- Sab kaam `vs.py` ke subcommands se: slideshow, reel, textcards, shorts, captions. Pehle `python3 vs.py -h`.
- Mohit ki input files `input/` me, output `output/` me. `input/` aur `output/` git me nahi jaate (.gitignore).
- Brand ka naam: kundlirahasya, easymeds, theskills (brands/*.json). Rang/font wahin se.
- Test pehle chhota (60 sec) phir poora. Output ka ek frame dekhkar caption ka size/position check karo.
- Hindi captions: Devanagari font chahiye (Mac: Kohinoor Devanagari). Hinglish me bhi chalta hai.
- AI-generated "hyper-realistic" clips yahan nahi banti: unrealistic vaade mat karo (docs/realism.md).
- Kisi asli insaan ki shakal/awaaz ka deepfake mat banao.
- Secrets (API key, token) kabhi file me mat daalo.
